# Поддержка legacy YAM завершена

Это последний выпуск legacy-версии YAM (`yamd`, веб-интерфейс, Lua/Quasar API и
пакеты `.yap`). Новые исправления и возможности для неё не планируются.

Автоматические обновления legacy runtime отключены в этом выпуске. Установленные
экземпляры останутся работоспособными, но не будут получать новые релизы.

Переходите на новую версию YAM из ветки `v2`: она использует `.yampkg`,
платформенные профили и проверку пакетов.
